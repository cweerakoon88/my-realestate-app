# PropOffer brand

The heritage crest (sibling of the CarOffer crest): an ink shield with a champagne-gold double border, a gold roofline and a white "P".

| File | Use |
| --- | --- |
| `propoffer-logo-horizontal.png` / `.svg` | Main logo on light backgrounds (website, documents, email signature) |
| `propoffer-logo-horizontal-white.png` / `.svg` | On dark or navy backgrounds |
| `propoffer-logo-stacked.png` / `.svg` | Square-ish spaces: business cards, posters, social cover images |
| `propoffer-crest.png` / `.svg` | Icon only: social profile pictures, app icons, stickers |

The PNGs are high resolution with transparent backgrounds, so use them anywhere. The SVGs scale to any size, but their lettering needs the **Cormorant Garamond** font (free from Google Fonts) to be installed. Otherwise use the PNGs.

## Colours

| Colour | Hex | Use |
| --- | --- | --- |
| Ink | `#1A1714` | Shield, "PROP", headings, dark backgrounds |
| Gold | `#B8924A` | "OFFER", buttons, highlights |
| Champagne | `#C9A96E` | Crest borders and roofline, accents on dark |
| Cream | `#FAF8F3` | Page background |

## Type

- Wordmark and headings: Cormorant Garamond, semi-bold, wide letter-spacing
- Body text: DM Sans

## Don'ts

- Don't stretch, rotate or recolour the crest.
- Keep clear space around the logo at least the width of the "P".
- Don't place the ink/gold logo on busy photos; use the white version on a dark overlay instead.
